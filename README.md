Aplicação web moderna e interativa dedicada ao jogador **Lamine Yamal**. O projeto conta com um sistema dinâmico de filtragem de fotos por categorias (Barcelona, Espanha, Conquistas) e visualização de imagens ampliadas via modal (Lightbox).

---

## 🚀 Funcionalidades

- **Filtro Dinâmico de Imagens:** Alterne entre as categorias (*FC Barcelona*, *Seleção Espanhola*, *Prêmios*) em tempo real sem recarregar a página.
- **Visualizador Lightbox (Pop-up):** Ao clicar em qualquer imagem, ela abre num modal ampliado com legenda.
- **Design Moderno e Responsivo:** Layout em tons escuros (*Dark Mode*) inspirado nas cores do Barcelona, otimizado para telemóveis, tablets e computadores.
- **Efeitos Visuais (*Hover*):** Transições suaves e efeitos de zoom ao passar o cursor sobre os cards da galeria.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e tags de marcação.
- **CSS3:** Variáveis CSS, Flexbox, CSS Grid e animações de transição.
- **JavaScript (ES6+):** Manipulação da DOM para lógica dos filtros e abertura/fecho do modal Lightbox.
- **Font Awesome:** Ícones interativos.
